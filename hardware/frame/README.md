# frame

立方体の枠の印刷用 STL。8 個の頂点のコーナージョイントと、12 本の稜の溝のある棒。透明な樹脂で印刷する前提。

| ファイル | 部品 | 個数 | 大きさ (この向きで印刷) | 体積 |
|---|---|---|---|---|
| `joint.stl` | コーナージョイント (腕 20mm の Y 字) | 8 | 20 x 20 x 20mm | 1.46cm³ |
| `bar.stl` | 溝のある棒 | 12 | 45.5 x 6.88 x 6.88mm | 1.37cm³ |
| `joint-deep.stl` | 同じジョイントで、溝を 1.0mm 深くしたもの | 8 | 20 x 20 x 20mm | 1.62cm³ |
| `bar-deep.stl` | 同じ棒で、溝を 1.0mm 深くしたもの | 12 | 45.5 x 7.88 x 7.88mm | 1.57cm³ |

合計約 28.1cm³ (deep の組は約 31.8cm³)。どちらも外の面を下に寝かせてある。

- 断面は 6.88mm 角。LCD 1 枚ごとに幅 2.38mm (LCD 2.18mm に片側 0.1mm) のスリットがあり、2 本のスリットは交わらない (外の壁 1.0mm、2 本の間 1.0mm、くわえる深さ 2.5mm)
- 組んだ立方体の外の稜は 85.5mm。LCD は各面の中央に置き、長い辺はスリットの奥から 0.1mm、短い辺は約 1mm 手前で止まる
- 棒はジョイントの腕の端に突き合わせる。LCD が両方のスリットを通るので、向きは LCD がそろえる
- 作り方と設計の説明は `../../simulate/README.md` (`cube_frame.py`)。作り直したら `simulate/build/cube_frame_print/joint0.stl` と `bar00_*.stl` をここに複製する (12 本と 8 個はそれぞれ同じ形)
- `-deep` の組は `DEPTH` を 2.5mm から 3.5mm にして作った (`CUBE_FRAME_DEPTH=3.5 CUBE_FRAME_BUILD=<別の場所> python cube_frame.py`)。断面が 7.88mm 角になり、増えた 1.0mm は立方体の内側に出る。外の稜は 85.5mm のまま。ジョイントと棒は必ず同じ組で使う (`joint.stl` と `bar-deep.stl` は合わない)。基板との干渉は生成のときに基板の箱を引いてあるが、FPC と FFC は CAD に入れていない。2026-11-09 に作り、印刷はまだ
