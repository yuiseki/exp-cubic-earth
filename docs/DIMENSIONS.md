# 寸法: ER-TFT040-3 と ER-PCBA5981-1

立方体の組み方と基板の置き場所を考えるための寸法。単位は mm。

出典:
- メーカーの 3D モデル `ER-TFT040-3-6011.STEP` (BuyDisplay の `ER-TFT040-3-6011.zip`、2024-08-26、SolidWorks 2023)。パネル `ER-TFT040-3` と基板 `ER-6011-Controller Board` の組立品で、FPC を折らずに平らに伸ばした状態で入っている。値は OpenCascade で各部品の外接箱と断面を取って読んだ
- `ER-PCBA5981-1_Datasheet` の 6 ページ (基板の外形図)

STEP の基板 (ER-6011-Controller Board) は、外形 32.00 x 48.20、CON1 が長い辺、CON2 が短い辺の中央という配置が、ER-PCBA5981-1 の外形図と一致する。

## 座標の取り方

パネルを表 (表示面) から見て、FPC の出る辺を下にする。原点はパネル外形の左下の角、X は右、Y は上、Z は手前 (表示面の側)。

## パネル ER-TFT040-3

| | X | Y | Z | 大きさ |
|---|---|---|---|---|
| 外形 | 0〜74.66 | 0〜76.54 | -2.18〜0 | 74.66 x 76.54 x 2.18 |
| 表のガラス (偏光板) | 0.25〜74.41 | 2.81〜76.29 | -0.70〜0 | 74.16 x 73.48 x 0.70 |

- 外形は正方形ではない (縦が 1.88 長い)。ガラスは左右と上が外形の 0.25 内側で、下にだけ 2.81 の縁がある。この下の縁から FPC が出る
- 表示領域 (480x480 の画素がある範囲) は STEP に入っていない。未確認
- 厚みのうち、表のガラスが 0.70、その奥の本体が 1.48

### FPC (平らに伸ばした状態)

パネルの下の辺から下へ伸びる。幅は途中で変わる (境目は ±0.5 程度)。

| Y | X | 幅 |
|---|---|---|
| 0〜-3.0 | 24.69〜52.69 | 28.00 |

先端の 20.50 幅の部分は、パネルの左右の中心 (X = 37.33) にそろっている。

## 基板 ER-PCBA5981-1

### 基板だけの寸法

部品面から見て、CON2 の辺を上、CON1 の辺を右にした座標。原点は基板の左下の角。

| | X | Y | 大きさ |
|---|---|---|---|
| 基板 | 0〜32.00 | 0〜48.20 | 32.00 x 48.20 x 1.60 (基板の厚み) |
| CON1 (20 ピン 1.0mm、FFC の口) | 24.18〜31.59 | 0.34〜26.64 | 7.41 x 26.30、高さ 2.72 |
| CON2 (パネルの FPC の口) | 6.00〜27.65 | 40.15〜46.00 | 21.65 x 5.85、高さ 2.11 |
| U2 (LT7680) | 8.50〜17.16 | 19.54〜28.20 | 8.66 x 8.66 |

- 部品は片面だけ。基板の厚み 1.60 と、部品の高さ (最も高いのは CON1 の 2.72) を合わせて 4.32。データシートは「FPC を折った状態で 4.5」
- CON1 の口は基板の右の辺 (X = 32.00) に向いていて、FFC は基板の外から挿さる。CON1 は右の辺から 0.41 内側
- データシートの外形図では CON1 の中心が基板の端から 14.29±0.5。STEP では 13.49 で、0.8 ずれている
- CON1 の 1 番がどちらの端かは、STEP からもデータシートの外形図からも読み取れていない。未確認
- 外形図は 32.00±0.3 x 48.20±0.3

### パネルとの位置 (FPC を伸ばした状態、STEP のまま)

パネルの座標で、基板は X 21.33〜53.33、Y -70.09〜-21.89 にあり、部品面は表示面と同じ向き (手前) を向く。基板の左右の中心はパネルの中心 (X = 37.33) にそろう。CON2 が上 (パネル側)、CON1 は右の辺。

### FPC を折った状態

実際には FPC をパネルの下の辺で折り返し、基板をパネルの裏に重ねる。折ると基板は裏返り、部品面はパネルの裏とは反対側 (立方体の内側) を向く。パネルを裏から見ると、CON1 は基板の左の辺になり、FFC は左へ出る。

折った状態の基板の上下の位置は、FPC の曲げ方で決まる。STEP には入っていないので未確認。パネルの下の辺から CON2 の口までの FPC の長さは 24.09 (FPC は CON2 にさらに 2.79 挿さっている)。
